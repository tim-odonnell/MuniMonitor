# LARA/BCC Notice — Court Injunction on 2021 Residential Code (Part 5) and Energy Code (Part 10) Rules

> Source PDF: ../source-pdfs/bcc-2021-code-injunction-notice.pdf (downloaded 2026-07-08).
> CODE-CURRENCY CRITICAL: per the July 7, 2025 Court of Claims stipulated order (Home Builders Assoc et al. v LARA), the rule sets adopting the 2021 IRC/IECC are enjoined; the 2015-edition-based rules REMAIN IN EFFECT while litigation continues. Re-check status before relying on edition-specific answers — this WILL change.

On July 7, 2025, an order was issued by the court in two cases before the Michigan Court of
Claims in Home Builders Assoc et al. v LARA et al. The order temporarily prevents LARA
from “taking additional steps necessary to apply or implement” two rule sets that would
update the Michigan Residential Code and residential Energy Code chapter while the
litigation remains ongoing. Both rule sets would adopt, in part, the 2021 International
Residential Code (IRC) and 2021 International Energy Conservation Code (IECC) residential
standards and were set to become effective on August 29, 2025.



While this stipulated order remains in place, the 2015 versions of the IRC and residential
provisions of the IECC standards currently adopted, in part, by each rule set will remain
valid and in effect. You may review the draft revisions to each rule set and a complete copy
of the court’s stipulated order by visiting each link below and clicking on “Final Rule
Language”:
