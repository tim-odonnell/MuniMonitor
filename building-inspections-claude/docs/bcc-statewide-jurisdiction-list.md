                                               Statewide Jurisdiction List
                                              Bureau of Construction Codes


The Statewide Jurisdiction List is a listing of all units of government within the state. There are three (3) levels of
jurisdiction (state, county, local) for each of the four (4) code disciplines (building, electrical, mechanical, and plumbing).
The code authority being administered and enforced by the jurisdictions, as specified in the List, includes the seven (7)
codes which make up the State Code according to MCL 125.1504(2).

If COUNTY is indicated, that unit of government receives code enforcement services from a county enforcing agency.

If LOCAL (city, township, or village) is indicated, that unit of government has their own program.

If STATE is indicated, the Bureau of Construction Codes is responsible for code enforcement in that unit of government.

The Statewide Jurisdiction List is updated after every Construction Code Commission meeting to show changes; i.e. units
of government which have newly assumed responsibility or those who have returned responsibility to the state or county
level. The date each change takes effect will appear directly below the level of jurisdiction.

Occasionally, local units of government request assistance from the Bureau of Construction Codes for plan review, permit
and inspection services. The assistance may be for a specific period of time or for an entire project. The Statewide
Jurisdiction List reflects temporary assistance within a local jurisdiction with an asterisk and details regarding that assistance
can be found at the end of the List under Assistance to Local Enforcing Agency.

This List was compiled to assist contractors and homeowners securing permits and requesting inspections. Code questions,
requests for permits, or requests for inspections should be directed to the appropriate enforcing agency. Questions for state
issued permits and inspections should be directed to the respective division within the Bureau of Construction Codes at
www.michigan.gov/bcc.
